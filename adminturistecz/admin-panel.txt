📌 Documentación del Panel de Administración de Sitios (PHP + MySQL)
🔧 Introducción

Este panel de administración ha sido desarrollado en PHP con conexión a MySQL para gestionar los sitios turísticos de la aplicación Turistecz.

Permite:

- Iniciar sesión en el panel de administración.

- Registrar nuevos administradores.

- Visualizar todos los sitios registrados.

- Editar la información de cada sitio existente.

- Insertar nuevos sitios en la base de datos.

En xampp, ir a config, dentro de config --> "service and port settings"

dentro clickamos MySql y cambiamos lo que hay en main port por 3307.

⚙️ Configuración del Puerto de MySQL

Recordar que, desde el panel de administración hay que parar el mysql80 mientras cambiamos los puertos
y volver a arrancarlo antes de volver a acceder al panel de adminstración.

Por defecto, MySQL en XAMPP utiliza el puerto 3306.
Si ya está siendo usado (por ejemplo, por MySQL Workbench), puede generar conflictos.

En este caso, se ha configurado MySQL en XAMPP para trabajar en el puerto 3307.

Pasos para cambiar el puerto en XAMPP:

Abrir el XAMPP Control Panel.

En la fila de MySQL, pulsar Config → my.ini.

Buscar las secciones [mysqld] y [client].

Localizar las líneas con:

port=3306


y cambiarlas por:

port=3307


Guardar el archivo y reiniciar MySQL en XAMPP.

Ahora vamos a localhostphpmyadmin, ahi creamos una nueva base de datos en la pestaña "SQL", 

copiamos el script de creación que se encuentra en la carpeta de adminturistecz.


⚙️ Configuración Inicial en XAMPP
1. Arrancar Apache y MySQL

Desde el XAMPP Control Panel, inicia los módulos Apache y MySQL.

2. Configurar la ruta del proyecto en Apache

En el archivo de configuración de Apache (httpd.conf), busca las líneas:

DocumentRoot "/xampp/htdocs"
<Directory "/xampp/htdocs">


y cámbialas por la ruta local de tu proyecto en tu ordenador (cada persona debe poner la suya). Ejemplo:

DocumentRoot "C:/Users/TuUsuario/Documents/proyectos/adminturistecz"
<Directory "C:/Users/TuUsuario/Documents/proyectos/adminturistecz">


Guarda los cambios y reinicia Apache desde XAMPP.


⚠️ Importante: recuerda también cambiar en el archivo config.inc.php (en el botón config de Apache en XAMPP).

-Añade $cfg['Servers'][$i]['port'] = 3307;  justo donde aparece en este ejemplo:

$cfg['Servers'][$i]['host'] = '127.0.0.1';
$cfg['Servers'][$i]['connect_type'] = 'tcp';
$cfg['Servers'][$i]['port'] = 3307; 

⚠️ Importante: recuerda también cambiar el puerto en tus archivos PHP de conexión.

Ejemplo (db.php):

$servername = "localhost";
$username = "root";
$password = "";
$database = "turistecz";
$port = 3307;

$conn = new mysqli($servername, $username, $password, $database, $port);

if ($conn->connect_error) {
    die("Error de conexión: " . $conn->connect_error);
}

Una vez hechos estos cambios, entra en http://localhost/phpmyadmin y crea la BBDD.
    - Copia el script que hay en esta carpeta, pégala en la pestaña de SQL > Continuar y comprueba 
    que te aperece en el menú de bbdd de la izquierda.

🌐 Endpoints del Panel de Administración

Ya configurado, los principales endpoints disponibles serán:

🔑 1. Login
http://localhost/login.php

Permite a los administradores registrados acceder al panel mediante correo y contraseña.

🆕 2. Registro
http://localhost/register.php

Formulario para registrar nuevos administradores en el sistema.

📋 3. Selección de sitios
http://localhost/select-sitios.php

Primer endpoint tras iniciar sesión.

Muestra la lista de sitios registrados.

Incluye botones para editar cada sitio.

➕ 4. Inserción de nuevos sitios
http://localhost/insert-sitios.php

Formulario que permite añadir un nuevo sitio turístico, rellenando los campos requeridos (nombre, descripción, localización, etc.).

🚀 Flujo de uso del panel

El administrador accede a login.php e inicia sesión.

Una vez autenticado, se dirige a select-sitios.php para ver los sitios disponibles.

Desde ahí puede:

Editar un sitio existente.

Ir a insert-sitios.php para crear un nuevo sitio.

✅ Conclusión

Con este panel de administración se logra gestionar de manera sencilla los sitios turísticos de la base de datos, asegurando un control completo desde una interfaz basada en PHP.

El cambio de DocumentRoot garantiza que el proyecto cargue correctamente desde su carpeta local.
El ajuste del puerto de MySQL a 3307 evita conflictos con MySQL Workbench y asegura un entorno de desarrollo funcional.
